# BCC: данные для тестовой оплаты

Проверено 30 октября 2026 года по [официальной коллекции BCC](https://documenter.getpostman.com/view/23274245/2s7YYo95nr).
Использовать только изолированный `/sandbox`; эти реквизиты не включают боевой эквайринг.

## Терминал

```dotenv
BCC_SANDBOX_MERCHANT_ID=00000001
BCC_SANDBOX_MERCHANT_NAME="TOO MERCHANT"
BCC_SANDBOX_TERMINAL_ID=88888881
BCC_SANDBOX_MAC_KEY=6BB0AC02E47BDF73D98FEB777F3B5294
```

Шлюз: `https://test3ds.bcc.kz:5445/cgi-bin/cgi_link`, валюта — `398` (KZT).
Публичные параметры: [пример покупки](https://documenter.getpostman.com/view/23274245/2s7YYo95nr#b530c56d-fdcc-4938-a620-b0c03240392d),
[компоненты тестового MAC](https://documenter.getpostman.com/view/23274245/2s7YYo95nr#dec9154b-b2b9-4801-8dab-04aa635e95d0).

## Успешная оплата и начисление

Наличие тестового терминала позволяет подготовить банковский запрос, но не заменяет
проверку итогового результата. Для автоматического начисления BCC должен настроить
уведомления на `https://ai-reply.kz:443/sandbox/api/v1/payments/bcc/notify` с Basic Auth.
Логин и пароль уведомлений берутся из серверных `BCC_CHECKOUT_NOTIFY_USERNAME`
и `BCC_CHECKOUT_NOTIFY_PASSWORD`; они не являются MAC-ключом или паролем кабинета.
`BCC_CHECKOUT_STATE_SECRET` остаётся только у сервера.

В [разделе уведомлений](https://documenter.getpostman.com/view/23274245/2s7YYo95nr#01cd529b-b069-4ad3-9971-f588124e6014)
банк просит передать URL, порт 443, метод POST, логин/пароль, сведения о TLS 1.2
и виртуальном хосте. Секреты передаются банку по согласованному защищённому каналу.
Приёмник реализован; сведения о фактической настройке на стороне банка пока не получены.
До этого `BILLING_SANDBOX_BCC_ENABLED=false` сохраняет создание оплаты выключенным.

`TRTYPE=90` документирует запрос проверки в течение 24 часов, но коллекция не содержит
схемы или примера ответа, гарантирующих исходный итоговый статус и сумму. Поэтому
он не используется как неподтверждённый способ начисления. Возврат браузера также
не подтверждает платёж. [Запрос статуса](https://documenter.getpostman.com/view/23274245/2s7YYo95nr#e5f98a0a-9d09-4874-b2ff-3acadbe42629).
