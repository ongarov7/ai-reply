# AI Reply для Mac

Нативная программа для macOS 14 и новее: живёт в строке меню и открывает строку ввода по ⌥Space.
Пишет ответы и сообщения через сервер AI Reply, распознаёт голос и копирует результат в один клик.
Аккаунт, тариф и лимит — те же, что в приложении на телефоне.

## Как пользоваться

- **⌥Space** (или иконка в строке меню → «Открыть AI Reply») — строка ввода появляется поверх окон и не забирает фокус у мессенджера.
- **Скопировали сообщение** в WhatsApp, Telegram или почте → открыли строку → сверху уже видно «Ответ на: «…»».
  Один клик по «Другу / Клиенту / Коллеге / Партнёру» (⌘1…⌘4) — и ответ готов.
- **Написать новое:** «напиши другу, что завтра давай погуляем» → Return.
- **Микрофон** (⌘D): живая волна, ✓ — распознать, ✕ — отменить. Текст встаёт в строку, по Return ИИ пишет сообщение.
- **«Копировать»** (⌘Return): ответ копируется, строка закрывается — вставьте ⌘V и отправьте.
  Можно включить автоматическую вставку (Настройки → Основные; macOS попросит разрешение).
- Строку можно перетащить, она запомнит место. Esc закрывает.

## Устройство

```
AirReply.xcodeproj         приложение (AppKit, без окна и иконки в Dock)
AirReply/                  точка входа, Info.plist, иконка, строки ru/kk/en
Packages/AirReplyKit/      вся логика и тесты
  AirReplyCore             API сервера, вход, токены в Keychain, баланс, генерация
  AirReplySystem           глобальная клавиша, буфер обмена, вставка, автозапуск
  AirReplyVoice            запись микрофона в AAC (m4a, 16 кГц, моно)
  AirReplyUI               строка ввода (NSPanel + SwiftUI), меню, настройки
Docs/DESIGN.md             требования к интерфейсу
scripts/                   иконки и выпуск DMG
```

Сервер выбирается в настройке сборки `AIREPLY_BACKEND_BASE_URL`: Debug — `https://ai-reply.kz/sandbox`,
Release — `https://ai-reply.kz`. В Debug можно указать локальный сервер:
`open "AI Reply.app" --args -AIReplyBackendURL http://127.0.0.1:18084`.

Программа использует существующие методы сервера: вход по коду из письма, `/api/v1/me`, `/api/v1/config`,
`/api/v1/me/consents`, `/api/v1/ai/compose`, `/api/v1/ai/reply`, `/api/v1/ai/transcribe`.
**Перед выпуском нужно задеплоить backend из ветки `Payment`:** без правки согласия новый пользователь Mac
(`platform: macos`) не сможет принять условия и начать генерацию.

## Сборка и тесты

Нужны Xcode 26.6 и macOS 14+.

```bash
xcodebuild -project AirReply.xcodeproj -scheme AirReply -configuration Debug build
```

```bash
swift test --package-path Packages/AirReplyKit
```

132 теста: API и обновление токена, вход, согласие, баланс, генерация и ошибки, буфер обмена, горячая клавиша,
вставка, запись голоса, логика строки, полнота переводов.

Сквозной тест с настоящим сервером и OpenAI (только локальный backend, `APP_ENV=development`, тестовый код входа):

```bash
AIREPLY_INTEGRATION_URL=http://127.0.0.1:18084 AIREPLY_INTEGRATION_OTP=<код> AIREPLY_INTEGRATION_AUDIO=<папка с ru.m4a, kk.m4a> swift test --package-path Packages/AirReplyKit --filter IntegrationTests
```

## Подпись, нотаризация и DMG для сайта

1. Владелец аккаунта Apple Developer (команда `2PK6339Q47`) создаёт сертификат **Developer ID Application**
   и ставит его в связку ключей этого Mac.
2. Один раз сохранить доступ к нотаризации (пароль приложения с appleid.apple.com):

```bash
xcrun notarytool store-credentials airreply-notary --apple-id <apple id> --team-id 2PK6339Q47
```

3. Собрать, подписать, нотаризовать и упаковать:

```bash
scripts/build-release.sh
```

Скрипт кладёт в `dist/` файл `AI-Reply-<версия>.dmg`, его SHA-256 и `macos-<версия>.json` для страницы загрузок.
Сборка универсальная (Apple Silicon и Intel), без Rosetta. Перед публикацией проверьте её на macOS 27.

## Приватность

- Токены — только в связке ключей (Keychain) этого Mac. Пароли не используются: вход по коду из письма.
- Скопированный текст читается, только когда вы открываете строку, и отправляется на сервер только по вашему действию.
  Пароли из менеджеров паролей (помеченные как скрытые) не читаются вовсе.
- Микрофон включён только во время записи. Запись удаляется сразу после распознавания.
- В журналы попадают только адрес запроса, код ошибки и номер запроса — никогда не текст.
